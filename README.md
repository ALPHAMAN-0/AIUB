# AIUB Study Materials & Lab Work

This repository contains academic materials, assignments, lab work, and study resources collected from different courses at AIUB.

## Overview

The folder is organized by subject and includes:

- AIUB_COURSE: course-related reports and documents
- AutoCAD: AutoCAD drawings and related study materials
- C#: programming notes and course resources
- DS Lab: Data Structures lab programs and assignments written in C++
- Lab Task: Java lab tasks and coursework
- Math: mathematics notes, study guides, and exam materials
- OOAD: Object-Oriented Analysis and Design notes, diagrams, and PDFs
- SRE: Software Requirements Engineering slides, notes, and supporting files

## Highlights

- Programming practice in Java and C++
- Data Structures lab exercises
- AutoCAD design files
- Mathematics and software engineering study materials

## Note

This repository is intended for educational and personal learning purposes.
